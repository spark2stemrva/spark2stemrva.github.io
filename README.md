# Spark2STEM site
1. Create a GitHub repo, upload all these files (keep the folders), and turn on Settings > Pages > Deploy from branch (main, root).
2. No-code dashboard: go to https://app.pagescms.org, sign in with GitHub, pick the repo. Open "Workshops" to add/edit/delete workshops and upload pictures; each save commits to GitHub and the site updates in about a minute.
   Open "Sign-Up Links" to paste in your form link when you have it (leave blank to show "Link coming soon").
3. Change colors in the :root block at the top of style.css. Replace YOUR-EMAIL@example.com in index.html.
